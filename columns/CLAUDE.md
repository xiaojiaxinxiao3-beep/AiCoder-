# AiCoder client — 多欄式賽博龐克 GUI 主題交接（給 Claude Code）

## 目標
- 專案：**AiCoder client**，Meteor Client addon，**Minecraft 26.3**
- 這次只做 **GUI 主題**：照 `design/columns.html` 做出「多欄並排」的賽博龐克風格。**不做任何模組功能。**
- 這是**獨立的主題**，直接取代 Meteor 預設主題，不需要做樣式切換。

## 設計參考
- `design/columns.html`：定稿設計稿，用瀏覽器開會動
- `design/cyber-columns.gif`、`design/cyber-columns-still.png`：預覽圖
- 設計稿裡的模組清單只是示意，實際以 Meteor 的資料為準

## 版面
Meteor 的 Modules 畫面（`ModulesScreen`）本來就是**每個分類一個視窗、左右並排**，跟這個設計一樣。
所以**不用改版面邏輯**，只要透過主題改每個元件的外觀。

- **欄位視窗**：寬約 162，欄距約 12，從畫面左上排過去，高度依模組數量自動延伸
- **分類**：Meteor 原有的 6 個分類，加上 addon 自己註冊的一個分類 **AICODER**（裡面目前沒有功能，先放空殼模組或留空都可以）
- **左上角 HUD 標籤**：`AICODER`（粗體、字距 5、白字加青色光暈）＋ `v0.3 // CLIENT`（洋紅、等寬字）＋ `サイバー・システム`（青）
- **右上角**：Meteor 原本的分頁列（Modules / Config / GUI / HUD / Friends / Macros / Profiles）

## 配色（只有洋紅和青，**不要黃色**）
| 用途 | 值 |
|---|---|
| 青（開啟狀態） | `#00f0ff` |
| 洋紅（標題、外框、停留狀態） | `#ff2a6d` |
| 紫 | `#b026ff`，只用在背景光點 |
| 白（開啟模組的文字） | `#eaf6ff` |

## 元件規格

### 欄位視窗本體
- 背景：上下漸層 `rgba(26,8,40,.62)` → `rgba(8,6,22,.70)`，用 Blur 模組模糊背景
- 外框：1px 洋紅 `rgba(255,42,109,.5)`
- 右下角**斜切 12px**
- 兩個底角外側各有一個青色定位框，線寬 2、帶光暈：左下是 L 形，右下是一條沿切角的短斜線

### 欄位標題（高 30）
- 底色：洋紅漸層 `rgba(255,42,109,.42)` → `rgba(255,42,109,.10)`
- 底線：1px 洋紅 `rgba(255,42,109,.75)`
- 內容從左到右：
  - 編號 `01`（小號等寬字、半透明白）
  - 分類名稱（大寫、粗體、字距 2.2、白字加洋紅光暈）
  - 靠右放模組數量 `[21]`（青色等寬字）
  - 收合箭頭 `▾`
- **AICODER 這一欄**：標題底色和外框改用**青色**，跟其他欄區分

### 模組列（高 19，字 10.5px）
- **關閉**：灰字，沒有底色
- **開啟**：
  - 白字
  - 底色是青色由左往右淡出 `rgba(0,240,255,.16)` → 透明
  - 左邊一條 2px 青色亮條
  - 右邊一顆 4px 青色菱形
  - 亮條和菱形都帶光暈
- **滑鼠停留**：
  - 洋紅 1px 內框，底色 `rgba(255,42,109,.14)`
  - 底部一條 2px 底線，洋紅與青交替並往右流動

### 提示框（停留時出現在該列右側）
- 寬約 230，左上切角 8
- 底色 `rgba(12,6,26,.97)`，要夠不透明，下面的字不能透出來
- 1px 洋紅外框，外圍有淡淡的洋紅光暈
- 內容由上到下：
  - 模組名稱（大寫、粗體）
  - 說明文字
  - 一行青色等寬字，例如 `MOD-0x2F · ENABLED`

### 背景
- 片假名混十六進位字元的**資料雨**：直排往下流，青色和洋紅混合，透明度約 0.42，上下兩端淡出
- 青、洋紅、紫三色的模糊光點緩慢漂移

## 動態（一個循環約 4 秒）
**原則**：慢、不規則，**不要轉圈，不要橫掃整個畫面的掃描線**。

1. **Logo 故障閃爍**
   - 每個循環在 12%、47%、81% 三個時間點各閃約 0.2 秒
   - 閃的時候 Logo 拆成洋紅和青兩層，左右錯開幾 px，各自只露出一段水平條帶，亮度跟著閃
2. **開啟模組的亮條和菱形**：各自以不同相位呼吸，亮度在 0.6～1 之間
3. **定位框**：忽明忽暗
4. **停留模組的底線**：往右流動
5. **資料雨**、**背景光點**：持續緩慢移動

**實作提示**：所有不規則運動都用「多個正弦波疊加、頻率取整數倍」來做，這樣循環才接得起來。設計稿裡的 `flow()` 函式可以直接照抄。

## Meteor 實作要點（已從 Meteor 原始碼查證）

### 主題類別
- **繼承 `MeteorGuiTheme`**，不要直接繼承 `GuiTheme`
  - 原因：`MeteorWidget.theme()` 會強制轉型成 `MeteorGuiTheme`，繼承它才能沿用 Meteor 內建的 W* 元件
- **註冊方式**：在 addon 的 `onInitialize()` 呼叫 `GuiThemes.add(new AiCoderGuiTheme())`
  - 主題名稱寫死是 `"Meteor"`，加入同名主題會**取代**原本的主題（log 會出現一筆錯誤，屬正常）
  - 所以同一時間只能裝一個這類主題 addon
- **顏色**：主題的顏色都是 public 的 `Setting<SettingColor>` 欄位，在建構子裡用 `.set(...)` 改成上面的配色，使用者之後也能在遊戲內自己調

### 要覆寫的工廠方法
| 方法 | 負責 |
|---|---|
| `window()` | 欄位視窗：標題列、外框、切角、定位框 |
| `module()` | 模組列：開啟、關閉、停留三種狀態 |
| `tooltip()` | 提示框 |

其他元件沿用 `WMeteor*`。

### 分類
- addon 在 `onRegisterCategories()` 裡用 `Modules.registerCategory(...)` 註冊 **AICODER** 分類
- 需要放空殼模組的話，在 `onInitialize()` 用 `Modules.get().add(...)` 加入

### 繪圖
- `GuiRenderer` 只有：四邊形（可做漸層）、`triangle()`、文字、貼圖，**沒有圓形和圓角**
  - 切角、菱形：用三角形拼
  - 亮條、底線：用四邊形
  - 光暈：疊幾層半透明、逐漸放大的形狀來近似
- **片假名需要支援 CJK 的字型**：在 Meteor 的字型設定裡選一個（例如 Noto Sans CJK）；沒有的話，資料雨就只用十六進位字元

### 動畫
- 用系統時間算相位：`phase = (System.currentTimeMillis() % 4000) / 4000.0`
