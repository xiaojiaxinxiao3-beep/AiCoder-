AiCoder 下載站

七個 Meteor Client 的 GUI 主題 addon，加上一個戰鬥巨集模組包（不含在「全部」裡）。每個都是獨立的 jar，可以只裝一個，也可以一起裝。Minecraft 26.3 和 1.21.11 各有一份，功能相同。

Minecraft 26.3 / 1.21.11 Fabric 需要 Meteor Client Java 25（26.3）· Java 21（1.21.11）

戰鬥巨集 · 九個模組

不是主題，是九個模組，放在 Meteor 介面裡自己的 AiCoder 分頁（圖中右上角）。只幫你按按鍵：切快捷列、對準心指到的東西點擊、真的轉動視角。

  • Anchor Macro：放下重生錨後自動補螢光石並引爆
  • Crystal Macro：放下水晶後自動點爆，按住右鍵就能連續炸；可選自動補黑曜石
  • Mace Swap：拿其他武器打人時，出手瞬間切成重錘再切回來
  • Mace Dive：鞘翅飛高、俯衝、換胸甲用重錘打，自動循環
  • Spear Lunge：按住按鍵連續長矛突進，放開就停
  • Right Clicker／Left Clicker：長按變連點，左右鍵是兩個獨立的模組
  • Crosshair Drift：設定距離內有玩家時，準心慢慢飄向他
  • Wind Pearl：丟珍珠後自動補丟風彈，預判兩者在空中相遇

AiCoder Assist · 注入式（1.21.11 與 1.21.4）

不需要 Meteor。先開 Minecraft（1.21.11 或 1.21.4，原版或用 Fabric 啟動的都可以；下載對應的版本），再執行，九個模組和兩個極光介面就會進到遊戲裡，按右 Shift 開啟。

  • 四種介面：極光玻璃與液態玻璃，各有多欄並排、單視窗三欄；選單上方的 STYLE 切換外觀
  • 液態玻璃可以調兩個顏色、透明度和背景圖片；自己的圖放進遊戲資料夾的 aicoder-assist-wallpapers
  • 十五個模組，包含 Telly Bridge（自動疊橋）、Offhand Totem（自動補圖騰）、Spear Smash（長矛接重錘）、Cart Bomb（火焰弓引爆 TNT 礦車）（1.21.4 版沒有長矛衝刺，因為那一版沒有長矛）
  • 內建六個小遊戲（選單上方的 GAMES）：落下方塊、貪食蛇、踩地雷、數字合併、打磚塊，還有一個可以挖和蓋的 2D 側視沙盒
  • exe 版可能被防毒軟體擋下（未簽章，而且它做的事就是注入）；沒有 exe 的版本用一個看得懂的腳本做同樣的事

AiCoder Assist · 基岩版（Windows 國際版）

先開 Minecraft 基岩版並進入世界，再執行 exe，回遊戲按右 Shift。不讀也不改遊戲內部，只幫你按滑鼠和數字鍵。

  • 十個模組：左右鍵連點、水晶、重生錨、錘切、長矛衝刺、風彈珍珠、風彈跳、鞘翅起飛、俯衝重錘；都能綁按鍵（Toggle／Hold）
  • 選單裡有和 Java 注入版同樣六個小遊戲（GAMES）：落下方塊、貪食蛇、踩地雷、數字合併、打磚塊、2D 沙盒
  • 全部是「照順序按數字鍵和滑鼠」，每樣東西在快捷列第幾格要自己設定；沒有自動瞄準，準心飄移沒有做
  • 只在 Wine 的替身程式上測過，沒有在真正的基岩版跑過；不支援網易版；防毒可能會擋

安裝方式

  1. 選和你的遊戲相同的版本（26.3 或 1.21.11），Meteor Client 也要是同一個版本。
  2. 按下載，確認儲存。拿到的是 .zip，解壓縮後裡面就是 .jar。
  3. 把 .jar 放進 Minecraft 的 mods 資料夾，和 Meteor Client 放在一起。
  4. 啟動遊戲，按 右 Shift 開啟 Meteor 的 GUI。地球科學和液態玻璃第一次安裝會自動套用。
  5. 之後想換主題：GUI 分頁最上面的 Theme 下拉選單。

自己的壁紙：把 PNG 或 JPG 放進遊戲資料夾的 meteor-client/aicoder-wallpapers，再到 GUI 分頁的 Wallpaper 下拉選單選它。兩個液態玻璃共用這個資料夾。

為什麼是 zip：這個頁面只能儲存特定幾種檔案類型，jar 不在其中，所以每個 jar 外面包了一層 zip。賽博龐克、地球科學、液態玻璃、極光玻璃這四個單視窗主題裡，點模組列是選取，點右邊的開關圖示或按右鍵才是開關模組，Ctrl+F 可以搜尋；多欄版和兩個直立式則是左鍵開關、右鍵設定。
