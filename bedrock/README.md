# AiCoder Assist — 基岩版（Windows，國際版）

注入到執行中的 Minecraft 基岩版。產物：`work/AiCoderAssist-Bedrock.exe`（注入器）與 `work/AiCoderAssist-Bedrock.dll`。

## 用法
1. 兩個檔案放在同一個資料夾
2. 開 Minecraft 基岩版，進入世界
3. 執行 `AiCoderAssist-Bedrock.exe`，回到遊戲按**右 Shift** 開選單
4. 選單右上角 `UNLOAD` 可以卸載

## 它怎麼運作（和 Java 版完全不同）
- **不讀、不改遊戲內部的任何東西**：沒有特徵碼、沒有掛遊戲函式，所以不會因為遊戲更新而失效
- 選單是蓋在遊戲視窗上的一個獨立視窗（開啟時遊戲會失去焦點，基岩版會自己暫停）
- 模組只透過 `SendInput` 按滑鼠鍵和數字鍵，和人按的一樣。它**看不到**你手上拿什麼、準心對著什麼
- 模組只在「遊戲視窗在前景、而且滑鼠游標是隱藏的」時動作（游標出現＝開了背包、聊天或選單）
- 不做任何隱藏：DLL 用自己的名字出現在遊戲的模組清單，視窗和行程都沒有偽裝

## 模組
每個模組都是「照順序按鍵」。它看不到物品欄，所以**每樣東西放在快捷列第幾格要自己在設定裡填**。

| 模組 | 做什麼 | 你要做的 |
|---|---|---|
| Left Clicker | 按住左鍵時連點（CPS 1～100、變化量、延後開始） | |
| Right Clicker | 按住右鍵時連點 | |
| Crystal Clicker | 按住右鍵時「打、放」輪流 | 手上拿水晶。`Obsidian Slot` 設成 1～9 時，每一輪會先切到那格放一塊再切回水晶（不管原本能不能放，都會放） |
| Anchor Macro | 你按一次右鍵放重生錨後：螢光石格 → 右鍵充能 → 回原格 → 右鍵引爆 | 建議綁 HOLD，只在要用時按住 |
| Mace Swap | 你的每一下左鍵變成：切到重錘格 → 攻擊 → 切回武器格 | 開著時你自己的左鍵會被攔下、改由巨集代按，所以也不能按住左鍵挖方塊 |
| Spear Lunge | 開著時重複：跳 → 切到長矛格 → 攻擊 → 切回 | 綁 HOLD，按住才動作。看不到飽食度，要自己放開 |
| Wind Pearl | 你按右鍵丟珍珠後，隔一段時間切到風彈格丟出、再切回珍珠格 | `Delay` 與 `Aim Shift`（丟風彈前把滑鼠上下移幾個像素，丟完移回）要自己試出來 |
| Elytra Launch | 按一下：跳 → 再跳（張開鞘翅）→ 切到煙火格使用 → 切回 | 已經穿著鞘翅 |
| Dive Strike | 按一下：切到胸甲格按右鍵換上 → 切到重錘格攻擊 → 再切回那格（現在是鞘翅）按右鍵穿回 → 切回武器 | 自己飛、自己瞄準，到攻擊距離時按 |
| Wind Jump | 按一下：切到風彈格 → 視角轉到正下方 → 跳的同時丟風彈 → 切回 | `Throw Delay` 是跳和丟之間的間隔（Java 版實測 0 最高）。它不知道你原本看哪裡，`Look Back` 填要把滑鼠往上移回多少像素，0 是不移回 |

每個模組都能綁按鍵，模式可選 TOGGLE／HOLD（設定最下面的 BIND；Esc／Backspace／右鍵清除）。Elytra Launch、Dive Strike 和 Wind Jump 是「按一下跑一次」，跑完自己關閉。兩種極光介面用右上角的 `WINDOW`／`COLUMNS` 切換。設定存在 `%APPDATA%\AiCoderAssist\bedrock.ini`。

## 和 Java 版效果不同的地方
- **Mace Swap**：Java 版是「一擊同時吃到兩把武器的效果」；這裡是單純「切重錘打一下再切回」，傷害就是重錘自己的
- **Spear Lunge**：按鍵順序和 Java 版一樣，但「切回去沒有冷卻」這個特性在基岩版有沒有成立，沒辦法在這裡驗證
- **Wind Pearl**：沒有預判，時間差和角度靠你自己調
- **Dive Strike／Elytra Launch**：取代 Mace Dive，但不會自動找人、自動飛、自動瞄準
- **Crosshair Drift（準心飄向玩家）沒有做**：它一定要知道別人的位置，只靠按鍵做不到

## 小遊戲（GAMES）
選單右上角的 `GAMES` 會把模組清單換成六個小遊戲，再按一次或按 `WINDOW`／`COLUMNS` 回到模組。和 Java 注入版是同一批遊戲。選單開著時基岩版本身是暫停的（失去焦點），所以是「暫停時玩」。

| 遊戲 | 玩法 | 操作 |
|---|---|---|
| Drop | 落下的四格方塊，排滿一列就消除 | 方向鍵移動與旋轉、下鍵加速、空白鍵直落、C 暫存 |
| Trail | 吃點變長，撞牆或撞到自己結束 | 方向鍵或 WASD |
| Sweep | 打開所有安全的格子 | 左鍵打開、右鍵標記 |
| Merge | 相同的數字合併成兩倍 | 方向鍵或 WASD |
| Bounce | 用板子接球打磚塊 | 滑鼠或方向鍵、空白鍵或點擊發球 |
| Dig | 2D 側視沙盒：地形、洞穴、礦石，可以挖和放 | A／D 走、W 或空白鍵跳、按住左鍵挖、右鍵放、1～9 或滾輪選格、連按兩次 N 換新世界 |

`P` 暫停、`R` 重新開始。最高分存在 `bedrock.ini` 的 `[games]`，Dig 的世界存在同一個資料夾的 `dig.dat`。

## 測試範圍
在 Linux 的 Wine 裡，用一個替身程式（`test/fakegame.c`：會隱藏游標並記錄收到的輸入，檔名取成 `Minecraft.Windows.exe`）測過：注入、提示、兩種版面、設定視窗、拖曳滑桿、綁定 G＋HOLD、Left Clicker（12 CPS 設定下 1 秒約 12 下）、Crystal、Anchor（收到 2、右鍵、1、右鍵）、Mace Swap（一下左鍵 → 2、左鍵、1）、Wind Pearl（右鍵 → 4、右鍵、3）、Spear Lunge（跳、3、左鍵、1 重複）、Elytra Launch（跳、跳、5、右鍵、1，只跑一次）、Dive Strike（6、右鍵、2、左鍵、6、右鍵、1，只跑一次）；六個小遊戲都開起來玩過幾步，Dig 挖了兩格、放回一格，關選單後 `dig.dat` 與最高分有寫出、游標顯示時不動作、UNLOAD 後再次注入。

**沒有在真正的基岩版和真正的 Windows 上跑過。** 測的只是「按鍵有照順序送出」，遊戲裡的實際效果都沒驗證。不確定的地方：
- 每一步之間的間隔（Step Delay）要多長遊戲才來得及反應；太短會漏步驟，請自己調大
- 基岩版對著已穿的胸甲／鞘翅按右鍵會不會直接互換（Dive Strike 靠這個）
- 遊戲是否接受 `SendInput` 的滑鼠與數字鍵（一般的巨集軟體是可以的）
- 遊戲在世界中是否真的隱藏系統游標（若不是，模組會完全不動作）
- 獨佔全螢幕時選單可能蓋不上去，請用視窗或無邊框
- 商店舊版（UWP）的行程能否載入 DLL（注入器已替 DLL 加上 ALL APPLICATION PACKAGES 的讀取權限）
- 防毒軟體很可能會擋注入器，原因和 Java 版的 exe 一樣；這裡不做任何規避
