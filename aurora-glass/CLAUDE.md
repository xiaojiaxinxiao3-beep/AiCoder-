# AiCoder client — 極光液態玻璃 GUI 主題交接（給 Claude Code）

## 目標
- 專案：**AiCoder client**，Meteor Client addon。
- 這次只做 **GUI 主題**：照 `design/` 裡的設計稿做出「極光 + 毛玻璃 / 液態玻璃」風格。**不做任何模組功能。**
- 要做**兩種版面**，各自是一個獨立的主題 addon（和現有的「液態玻璃」「液態玻璃直立式」同樣的分法）：
  - **Aurora Glass**：單視窗三欄（分類 / 模組 / 設定）。
  - **Aurora Glass Columns**：多欄並排（每個分類一欄）。
- 目標版本：Minecraft **1.21.11** 與 **26.3** 各一份。兩個版本的 Meteor API 不同，不能共用 JAR。
- 主題直接取代 Meteor 預設主題，不需要做樣式切換。

## 設計參考
- `design/aurora-window.jpg`：單視窗三欄版面定稿圖。
- `design/aurora-columns.jpg`：多欄並排版面定稿圖。
- `design/aurora.html`：設計稿原始檔，用瀏覽器開啟。網址加 `?layout=a` 看單視窗、`?layout=b` 看多欄；加 `&tab=shoreline` 看 Shoreline 分頁被選中的樣子。所有顏色、圓角、間距的數值都能從這個檔案的 CSS 直接讀到，以它為準。
- 設計稿裡的模組清單只是示意，實際以 Meteor 的資料為準。

## 一定要遵守的相容性
- 分類清單必須用 `Modules.loopCategories()` 取得，分頁列必須遍歷 `Tabs.get()`，被選中的分頁用 `screen.tab == tab` 判斷。
  Shoreline 插件靠這三點把自己的模組放進獨立的「Shoreline」分頁；不要自己寫死 6 個分類或 7 個分頁。
- 不要寫死分類數量與欄數：多欄版面在 Modules 分頁是 6 欄，在 Shoreline 分頁也是 6 欄，但其他插件可能加分類。
- 搜尋結果用 `Modules.get().searchTitles(...)` / `searchSettingTitles(...)`。

## 配色（深夜藍底，極光綠 → 青 → 紫，粉紅只當點綴）
| 用途 | 值 |
|---|---|
| 夜空底色（最深 / 中 / 淺） | `#030712` / `#071226` / `#0c1d3a` |
| 極光綠（開啟狀態主色） | `#4dffb8` |
| 極光青 | `#2fe6e0` |
| 極光紫 | `#8f7bff` |
| 極光粉（只用在背景光帶與外框漸層） | `#ff6fd8` |
| 主文字 | `#eefaff` |
| 次要文字 | `rgba(226,244,255,.62)` |
| 最淡文字（編號、提示） | `rgba(226,244,255,.36)` |
| 玻璃邊緣高光 | `rgba(255,255,255,.34)`，淡版 `rgba(255,255,255,.14)` |
| 輸入框 / 滑桿軌道底 | `rgba(3,10,26,.42)` |

「極光漸層」固定為：綠 `#4dffb8` → 青 `#2fe6e0`（約 55%）→ 紫 `#8f7bff`，由左到右。
不要用黃色、橘色、純紅色。

## 字體
- 介面文字：Comfortaa（Meteor 內建字體即可），標題與分類一律大寫並拉開字距。
- 編號、數值、狀態列：等寬字（JetBrains Mono 或 Meteor 的等寬字）。

## 液態玻璃表面（所有面板共用）
這是整個主題的核心，每個視窗、欄位、分頁列、提示框都是同一種表面：
1. **背景模糊**：面板後方的遊戲畫面要模糊（用 Meteor 的 Blur 模組 / 主題的模糊鉤子），強度約 30px，並略微提高飽和度，讓極光的顏色透進來。
2. **玻璃底色**：左上到右下的白色漸層，`rgba(255,255,255,.16)` → `.055` → `.03` → `.10`，中間最透、兩端較亮。
3. **邊框**：1.4px 漸層外框，左上是亮白 `rgba(255,255,255,.85)`，中段轉極光綠與極光紫（各約 .42 透明度），右下回到白 `.55`。這條邊是「液態」感的來源，不能省略成單色邊。
4. **上緣高光**：面板內側上方有一片柔和的白色高光（從左上往下淡出，最亮約 .16），外加頂端 2px 的內側亮線 `rgba(255,255,255,.30)`。
5. **陰影**：`0 28px 70px rgba(0,6,20,.52)`，讓面板浮在背景上。
6. **圓角**：主視窗 28、欄位 24、模組列與分類鈕 18、小元件 10–12、分頁列與開關為全圓角（膠囊形）。

提示框是例外：底色要夠不透明（`rgba(20,44,78,.93)` → `rgba(8,18,42,.95)`），下面的字不能透出來，但邊框與高光照舊。

## 背景
- 開啟 GUI 時，遊戲畫面上疊一層夜空色調並模糊。
- **極光光帶**：三條大範圍、強模糊（約 46px）的斜向光帶，用加亮混合：
  - 左上：綠 → 青，微微左傾。
  - 右上：紫 → 粉，微微右傾。
  - 中段：青 → 綠 → 紫，幾乎水平，較淡。
- **極光簾幕**：光帶區域內疊一層細直條紋（淡綠與淡紫交錯，透明度約 .1），上下兩端淡出，做出極光垂墜的紋理。
- **星點**：畫面上半部散佈約 400 顆白色小點，大小與亮度不一。
- 四周加暗角，讓中央的面板更突出。

## 版面一：Aurora Glass（單視窗三欄）
以 1920×1080 為基準，視窗寬 1260、高 780，置中。

- **頂部分頁列**：畫面上方置中的膠囊形玻璃條。每個分頁是膠囊鈕，字距 2.6；被選中的分頁填滿極光漸層（綠 → 青 → 淺藍），深色文字，外圍綠色光暈。
- **標題列**（高 74）：左邊 `AiCoder client`，其中 `client` 用極光漸層文字並帶淡綠光暈；右邊兩顆小膠囊標籤（主題名稱、狀態）。
- **左欄 分類**（寬 250）：每個分類一顆圓角 18、高 58 的鈕，內容為「狀態圓點 + 分類名（大寫）+ 模組數（等寬小字，靠右）」。
  - 未選中：淡玻璃底 `rgba(255,255,255,.045)`，次要文字色。
  - 選中：極光漸層半透明底（綠 .30 → 青 .20 → 紫 .26），白色內框，下方青色柔光，圓點變綠並發光。
- **中欄 模組**（寬 400）：每個模組一列，高 66、圓角 18，左邊模組名（16.5px）加下方的等寬編號 `MOD-0x__`，右邊一顆開關。
  - 關閉：淡玻璃底。
  - 開啟：淡極光漸層底加淡綠內框。
  - 目前選取（右欄顯示其設定）：白色亮內框，外加一圈淡綠外暈。
  - **開關**：44×24 的膠囊。關閉是暗色凹槽加白色圓鈕在左；開啟是極光漸層填滿、圓鈕在右、外圍綠色光暈。
- **右欄 設定**：標題「模組名 · SETTINGS」加右上角的收藏星號，下面一行說明文字。
  - 群組標題（GENERAL、PLACE…）：極光綠小字、字距 3.4，右側拉一條「綠 → 紫 → 透明」的細線。
  - 每一列：標籤、輸入元件、滑桿、重設鈕（圓形細框加 ↺）。
  - **數值框**：圓角 10 的暗色凹槽，等寬字。
  - **滑桿**：8px 高的暗色軌道，已填部分是極光漸層並發光；把手是 20px 的白色立體圓珠，外圍一圈淡白環。
  - **核取方塊**：24px、圓角 8。勾選時填極光綠 → 青漸層並發光，深色勾號。
  - **下拉選單**：和數值框同樣的凹槽樣式，右側 ▾。
- **底部狀態列**（高 52）：等寬小字，顯示開啟 GUI 的按鍵、FPS、延遲、已啟用模組數；最右邊一組極光漸層的等化器小柱。

## 版面二：Aurora Glass Columns（多欄並排）
Meteor 的 `ModulesScreen` 本來就是每個分類一個視窗、左右並排，所以**不用改版面邏輯**，只透過主題改每個元件的外觀。

- **左上角標誌**：`AICODER client`，`AICODER` 用極光漸層文字、字距 6；下方一行等寬小字。
- **右上角分頁列**：和版面一相同的膠囊形玻璃條，靠右。
- **欄位視窗**：寬 252、欄距 14、圓角 24，從畫面左上排過去，高度依模組數量自動延伸。
- **欄位標題**（高 54）：由左到右為「編號 `01`（等寬小字、最淡文字色）、分類名（大寫、粗體、字距 3.4）、模組數（小膠囊標籤，靠右）、收合箭頭 ▾」，下緣一條淡白分隔線。
- **模組列**（高 31、圓角 11、字 14px）：
  - 關閉：次要文字色，沒有底色。
  - 開啟：主文字色；底色是極光漸層半透明（綠 .30 → 青 .14 → 紫 .20）；淡綠內框；最右邊一顆 7px 的綠色發光圓點。
  - 滑鼠停留：主文字色，底色 `rgba(255,255,255,.11)`，白色內框。
- **提示框**（停留時出現在該列右側）：寬約 300、圓角 18。由上到下為模組名稱（大寫、字距 2.4）、說明文字、一行極光綠等寬字，例如 `MOD-0x21 · DISABLED`。
- **搜尋欄**：最右邊一個較窄的欄位（寬 224），裡面一個暗色凹槽輸入框。
- **右下角**：兩行操作提示，最淡文字色。

## 動態
**原則**：慢、柔和，像極光在飄；**不要閃爍、不要掃描線、不要旋轉**。
1. **極光光帶**：三條光帶各自以 18–30 秒的週期緩慢橫向漂移並輕微改變亮度，相位錯開。
2. **極光簾幕**：直條紋以很慢的速度橫向流動。
3. **玻璃邊框**：邊框漸層的角度以約 12 秒一圈緩慢轉動，看起來像光在玻璃邊緣流動（只轉漸層，面板本身不動）。
4. **開啟的模組**：綠色圓點與漸層底以 2.4 秒週期呼吸，亮度在 0.7–1 之間，各列相位錯開。
5. **切換開關**：圓鈕 160ms 滑動，漸層同時淡入。
6. **滑鼠停留**：底色 120ms 淡入。
7. **開啟 / 關閉 GUI**：面板在 180ms 內由 96% 放大到 100% 並淡入。

動態全部做成可在 GUI 設定裡關閉（一個「Animations」開關），關閉時顯示靜止的定稿樣子。

## 實作注意事項
- 兩種版面都繼承 `MeteorGuiTheme`，覆寫各個 `W*` 元件的繪製；單視窗版另外覆寫 `modulesScreen()` 回傳自訂的三欄畫面，並同步覆寫 `isModulesScreen(...)`。
- 現有的「液態玻璃」「液態玻璃直立式」兩個專案是最接近的起點：版面邏輯可以直接沿用，主要是換配色、玻璃表面的畫法與背景。
- 圓角、漸層外框、柔光都要自己用 Meteor 的渲染器畫；設計稿裡的 CSS 效果只是外觀參考，不能直接搬。
- 背景模糊在沒有獨立顯示卡的機器上很吃效能，請提供關閉模糊的選項；關閉時玻璃底色改用較不透明的版本（約 .55 的深藍），其餘外觀不變。
- 文字一律用主題的文字繪製方法，不要自己載字體檔。
- 1.21.11 的主題建議用正式安裝方式測試（打包後的 JAR 加 Meteor JAR），開發模式下 Meteor 自己的 mixin 可能套用失敗。

- 兩種版面在 Modules 分頁與 Shoreline 分頁都能正確顯示各自的分類，分頁列的選中狀態正確。
